Google Docs Share Modal – UI Component Replication
Reference Component Chosen

For this assessment, I chose to replicate the Share modal dialog from Google Docs.

This includes the main Share interface that appears when a user clicks the “Share” button inside a document. I focused specifically on recreating the core interaction areas of this modal while keeping the scope limited to a single UI component.

The implemented sections include:
1. Modal header (Title, Help icon, Settings icon)
2. “Add people” search input field
3. “People with access” section
4. “General access” section
5. Copy link functionality with feedback notification
6. Primary action button (“Done”)

Functional Overview
The modal is fully interactive using mocked data and frontend-only logic.

Implemented Behaviors

1. Add people input
2. Displays email suggestions on focus
3. Clicking a suggestion adds a user to “People with access
4. People with access
5. Displays owner information (name + email)
6. General access to allow the document to stay restricted ot accessed by anyone with the link.
7. The person can be chosen as vieer, commentor or editor

External Libraries & Tools

1. Used HTML, CSS and JavaScript without extra qualifiers. 
2. Font Awesome (for icons like help, settings, and link).

Workflow Efficiency Report

1. Used Chrome DevTools to accurately extract font sizes, colors and spacing from the reference UI, minimizing guesswork.
2. Used GitHub Copilot selectively to speed up repetitive coding patterns while maintaining full control over implementation decisions.
